# M8 工厂 AI 巡检、机组自动化与认证记录

> 本页是复刻路线图 M8 阶段的第三篇 prompt:让工厂里的摄像头、制冷机组和认证记录三件事「自己转起来」——摄像头按规则巡检并留证据,机组收工自动关机、能按工单判断何时下班,认证记录表一键生成、每月自动归档。适合已做完 M5 生产与 M7 冷链 IoT 的团队,以及他们的 AI 编程助手。

## 读完你会知道

- 三个子系统各自的最小领域模型与接口契约(示意)
- 哪几条护栏必须写进 prompt:多帧确认与冷却、令牌只开只读、冻库守卫与红线房间、成对恢复、缺就写缺
- 为什么工单驱动关机的参数必须先回放再上线
- 一份验收清单,重点验的是**自动化会不会悄悄做错事**

## 目标

- **A 摄像头 AI 巡检**:每台机位独立规则与间隔,抓拍 → 视觉大模型判定 → 多帧确认 → 冷却去重 → 红框证据;违规台账带误判闭环;监控墙免登;按批次回溯逐工序影像。
- **B 机组联网与自动关机**:两类接入统一状态出口;开关机变更流水;告警分级推送;收工两档自动关机 + 守卫 + 次日恢复;工单驱动关机 + 回放;读数保留期与小时聚合。
- **C 认证记录自动生成**:按认证条款把已有数据排成表,零依赖出 Word/Excel,缺口体检,每月自动归档。

背景模式篇见[工厂摄像头 AI 巡检](../../02-modules/factory-ai-inspection.md)、[机组联网与收工自动关机](../../02-modules/equipment-automation.md)、[认证记录自动生成](../../02-modules/certification-records.md)。

## A. 摄像头 AI 巡检
模型:巡检规则 VisionRule(名称唯一、判定说明、严重级、启用、已知误判排除说明);
机位 CameraSpot(设备号、通道、区域、启用、上墙、抓拍间隔秒[示例:最短 90]、确认帧数、冷却秒、
勾选规则、本机位补充说明、绑定工位码可手填、是否存档);违规 ViolationEntry(机位、违规项、逐人位置描述、
证据图、状态 待复核/属实/误判、误判原因枚举、处理人与时间);存档 SnapshotArchive(机位、时间、图片);
全局配置(巡检时段可跨零点、暂停开关)。
1. 定时节拍每分钟一次:先判时段与暂停,再派发到期机位;派发错峰;单机位加互斥锁,上一轮没完不派;
2. 未勾规则的机位只抓拍刷新快照,不调模型;
3. 勾了规则:抓拍 → 规则说明 + 排除说明拼提示词 → 模型返回 {是否违规, 违规项, 位置框, 逐人描述};
   N 帧中 M 帧命中才算;同机位同违规项冷却期内不重复落库;证据图画红框存对象存储;每次成功抓拍写存档;
4. 「测试判定」:立即抓拍 + 判定同步返回,不落库、不进冷却;
5. 复核:标属实/误判,误判必选原因;准确率 = 属实/(属实+误判),待复核不进分母;
6. 批次回溯:输入批次号或工单号 → 逐工序时间轴(工位、操作人、起止 ± 余量)+ 该工位机位的存档图与同窗违规;
   没走逐道工序 → 降级为全程窗口并标注;工位没绑机位 → 返回「无覆盖」标记,禁止返回空列表;
7. 存档按 [示例:120] 天清理,并在对象存储配置同前缀、同期限的过期规则;
8. 监控墙:机位列表(在线态、最近快照、摘要)+ 今日统计 + 违规增量接口(按游标);
   免登令牌 = 服务端签名 + 有效期 + 密钥编号,每类屏一套独立密钥,改编号即该套全部作废;
   令牌只放行监控墙这两个只读接口;鉴权先判登录再判令牌;敏感字段在服务端裁剪。

## B. 机组联网与自动关机
模型:机组 Unit(编号、房间、房间用途、接入类型 云/总线、期望状态);分钟读数 UnitSample(库温、开关、
设定、风机、压缩机、故障、来源);小时聚合 UnitSampleHourly(最小/最大/平均/条数);状态事件 UnitEvent
(类型 开关/设定温度/故障/风机/压缩机/其他、旧值、新值);告警 UnitAlarmLog(平台告警号唯一、严重级、
发生/结束时间、是否已推);收工动作 OffhoursAction(班次日、机组、档位、动作、原期望状态、复核结果);
免检 SkipNight(班次日、操作人、是否撤销)。
1. 统一状态出口:一个函数返回全厂每台一行 + 可选中文摘要,页面与机器人只许调它;
   读不出「关机」与「到温停机」区别的机组,「关」只代表此刻没在转,并带「不确定」标记;
2. 每分钟采集时同轮刷新状态项(不额外调云);与上次值比较,变化写 UnitEvent,风机/压缩机只记停↔转;
3. 告警:定时拉取,按平台告警号去重;接口返回全量时自行按设备过滤;首轮回填不推;
   分级:冻库新告警即推(每台每日上限)、非冻库同名重复达 [示例] 次推汇总、最高级持续超 [示例] 分钟推;
   文案与文档不得承诺「故障一定推送」,失冷兜底仍是 M7 的温度看门狗;
4. 收工关机:档位 [示例:22:00 车间类;01:00 打包与速冻类],每轮只处理本档名单;按房间用途排除;
   成品库、原料库写成代码硬红线,配置里出现也拒绝;冻库类压缩机在转不下发,车间类不加此守卫;
   免检读 SkipNight,班次日 = 凌晨 [示例:5] 点前算前一天;下发走人工控制同一通道,操作人记 system;
   每台每班次日只下发一次;等 [示例:5] 分钟复核,推一条合并消息
   (已关闭/仍在运行/关不掉请现场/开着但不在名单/数据过期);两个总闸:推不推、关不关;
5. ★成对恢复:关机时记下原期望状态并置为关;每天 [示例:06:00] 只恢复本系统改过、且夜里没被人改过的;
6. 工单驱动关机:每个房间配起评时刻、缓冲分钟、是否下游领料型、机组组;只看本房间工位的工序。
   未到起评 → 不评估也不让位;当天无工序 → 交固定档;有在产 → 保持开并让固定档跳过(不记已尝试);
   普通房间 → 最后完工 + 缓冲后关;下游领料型 → 本房间当天工单的下游工序全部已开工才关,
   时刻 = 最后完工与最晚开工取晚者 + 缓冲,否则整夜保持开并在凌晨发一条说明;
   次日 [示例:01:00] 兜底:判不出收工就关(下游领料型除外);领料信号只认下游工序开工时间;
   定时任务的运行时段必须覆盖所有房间的起评时刻;
7. 回放函数:输入天数,用历史工单与状态事件逐日模拟每个房间的关机时刻、早关台·小时、误关次数,
   输出参数对比表;改起评时刻、缓冲或判定范围前必须先跑;
8. 保留期 [示例:60] 天:过期分钟数据先聚合进小时表,再分小批删除并停顿;每台最新一条永不删;
   新增回看窗口不得超过保留期。

## C. 认证记录自动生成(纯读,不建业务表)
1. 表单目录:每张表一项(编码、名称、认证条款、数据源、是否可出、需手填列说明、无源原因、
   空档扫描范围 每日/仅生产日/不扫);请求无源表时返回 code=-1 + 原因,禁止生成空表;
2. 出表格式:doc / xls(带样式 HTML 表格 + Office 文件类型)、csv(UTF-8 BOM)、html;
   软探测原生文档库,有则自动用;表头 + 数据 + 页脚「系统生成,打印后手签方为有效」+ 四格签字栏;
   数值照抄不圆整、不重新判定;单表行数上限 [示例:10000];
3. 缺口接口:无数据源 / 记录空档(温度按日历日、生产类只看有生产活动的日子)/ 字段缺失 / 本期零记录
   + 专项空档(有关键控制点工序却零实测的工单、完工无出厂检验、启用却零读数的温控点等);
4. 月度归档:每月初凌晨生成上月全部可出表 + 缺口清单 + 包内目录 csv → 打包 → 私有对象存储(登录后下载)
   → 工厂群一条链接;单表异常写进目录不拖垮整包;上传失败落本地并如实告知;
   手工触发与定时调同一函数,手工不发群;任务第一行做环境守卫,非生产环境不写存储、不发消息。

## 接口契约(示意,全部 POST JSON,鉴权默认要登录)
| 动作 | 入参 | 出参 |
|---|---|---|

| 违规复核 | 记录 id、属实/误判、误判原因 | 更新后的记录 |
| 准确率统计 | 起止日期 | 总体 + 按违规项/机位/周 + 误判原因分布 |
| 批次回溯 | 批次号或工单号 | 工序时间轴 + 存档图 + 同窗违规 / 无覆盖标记 |
| 监控墙数据、违规增量 | 令牌或登录;游标 | 机位列表与统计;新增违规与新游标 |
| 机组状态 | 是否要中文摘要 | 每台一行 / 摘要文本 |
| 状态事件 | 机组、天数(有上限)、类型 | 事件列表 |
| 今晚免检 / 撤销 | 班次日(默认今晚) | 执行结果 |
| 表单目录、生成一张表、缺口、手工归档 | 起止日期、格式 | 目录 / 文件链接 / 缺口清单 / 归档包 |

## 红线
- AI 只标记不处罚;误判排除说明只许收窄误报;
- 成品库、原料库永不自动关;任何改了守护状态的自动化必须有成对恢复;
- 不承诺告警必推;回看窗口不超过保留期;
- 认证表缺就写缺,不替代签字,纯读不写业务数据。

## 验收清单

- [ ] **多帧与冷却**:让一个人连续违规,台账在冷却期内只出现一条;单帧误命中不落账
- [ ] **未勾规则不调模型**:该机位只有快照刷新,模型调用量不增加
- [ ] **令牌只开只读**:用墙面令牌调用「处理违规」接口被拒;改密钥编号后旧链接全部失效
- [ ] **无覆盖**:回溯一个工位没绑机位的批次,该工序显示「无覆盖」而不是空白
- [ ] **变更流水**:手动开关一台机组,下一轮采集后流水里出现事件,且没有新增云调用
- [ ] **红线房间**:在配置里把成品库加进关机名单,系统仍拒绝下发
- [ ] **冻库守卫**:模拟速冻压缩机在转,该轮不下发;压缩机停转时才下发
- [ ] **只下发一次**:同一班次日重复触发收工任务,每台只下发一次
- [ ] **成对恢复**:关机次日早上,被系统改过的期望状态恢复;夜里被人改过的不动
- [ ] **下游领料**:构造「腌制完工但下游未开工」,该房间整夜保持开,兜底不生效
- [ ] **回放先行**:回放输出每个房间的关机时刻与误关次数对比表
- [ ] **缺就写缺**:请求一张无数据源的表,返回原因而不是空表
- [ ] **归档隔离**:让一张表抛异常,月度包照常生成,目录里记下该表异常
- [ ] CLAUDE.md 已更新

## 踩坑与红线

- **症状**:被关过一次的机组,下一次停电后没有自愈。
  **根因**:关机置了「期望 = 关」,看门狗永久跳过,没人恢复。
  **铁律**:改守护状态的自动化必须成对出现。

- **症状**:工单驱动关机几乎天天判不出收工。
  **根因**:按整张工单判,下游工序常隔天补报。
  **铁律**:只看本房间工位;改判定范围前先跑回放。

- **症状**:监控墙用了一周变成登录二维码。
  **根因**:墙面机器挂着个人登录态,到期不续。
  **铁律**:免登令牌只开只读接口,装机后清掉一切登录态。

- **症状**:审核员拿到一张全空的「清洁消毒记录表」。
  **根因**:无数据源的表也被生成了出来。
  **铁律**:缺就写缺,请求无源表返回原因。
